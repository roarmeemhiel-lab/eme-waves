# 🌐 EM Spectrum Explorer

**Science 9 · Grade 9 · Electromagnetic Spectrum Interactive Learning Tool**

## 📚 Overview

EM Spectrum Explorer is an interactive web application for Grade 9 Science students to learn about the Electromagnetic Spectrum.

### Features:

* 🎯 Interactive Spectrum Bar
* 🤖 AI Tutor
* 🧮 Wavelength ↔ Frequency Calculator
* 🎮 Quiz Games (Solo, Group, Teacher modes)
* 🤗 Accessibility Mode
* 📊 Leaderboard

## 🚀 Live Demo

[Launch App](https://script.google.com/macros/s/your-app-id/exec)

## 📖 How to Use

1. Enter your name (Solo mode)
2. Choose difficulty level
3. Click "New Game"
4. Answer 10 questions
5. Check the leaderboard!
